# Portfolio — Nagaraju Chinthalacheruvu

Personal portfolio site for **Nagaraju Chinthalacheruvu**, Senior Frontend Engineer | AI Engineer at Intuit (Dallas, TX).

Single-page site: hero, stats, grouped skills, experience timeline, a grid of 11 live apps (SupportPilot, InvoicePilot, MarsRAG, VoicePilot, ModGuard, MCP Guard, FrontDesk AI, WebPilot, EdgeMind, ReelForge AI, KidsPlay), freelance services, and a contact footer.

## Stack

Next.js 16 · TypeScript · Tailwind CSS 4 · deployed on Vercel.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```

Content lives in `src/data.ts` — edit projects, skills and experience there.
